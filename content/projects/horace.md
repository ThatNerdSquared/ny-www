Horace was an open-source Discord bot I worked on in 2020 and 2021. It had a
broad set of community management features centered around a specific Discord
community dedicated to self-improvement, with some interesting features like
generating messages in special formats and running interactive activities for
community members.

This was the first sizeable software project I ever worked on. Luckily, there
were many more experienced developers on this project that were willing to teach
me how things worked and let me experiment with implementing different features.

Horace was where I learned the ropes: figuring out how git works, learning
Javascript, and getting my hands around what working on a fairly large project
is like. I remember struggling with JS promises, structuring clean control flow,
and learning the APIs of various npm packages. These are things that seem
trivial to me now, but that were real challenges when I was first learning how
to code!

Although I stepped away from the project in late 2021, I'll always be grateful
for the devs that mentored me on this project. They taught me a lot and helped
me get started with programming - and I'm still friends with some of them today!
