Hyperfocus was a collaborative pomodoro timer I built in early 2021. This was my
first solo software project, something that can be seen in the visual design and
code quality.

Although many decisions I made during the project feel amateurish looking back,
I learned a *lot* while building this. It was my first time building a
full-stack web app, working with REST APIs and Websockets,  deploying something
to production... even learning CSS Grid at 4 in the morning. Hyperfocus also
helped me fully appreciate the importance of well-structured, readable code —
nothing beats learning from experience!

Notably, it's also my last project to use a significant amount of vanilla
Javascript. I learned about Typescript halfway through, and the type-conversion
bugs + structural issues I encountered during this project were enough to
convince me to make the switch going forward.

While this project is mostly defunct today, I still look back at it with some
nolstalgia. I'm hoping to bring it up to speed with my current skillset at some
point - probably giving it a top-to-bottom rewrite along with a new look.
