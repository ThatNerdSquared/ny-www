Hyperfocus was a collaborative pomodoro timer I built in early 2021. This was my
first solo software project, something you can see in the visual design and code
quality.

Although many of my technical and aesthetic decisions didn't age well, I learned
a *lot* from building Hyperfocus. It was my first time building a full-stack web
app, working with REST APIs and Websockets, deploying something to production...
even my first time using CSS Grid. This project also helped me fully appreciate
the importance of well-structured, readable code — nothing beats learning from
experience!

While this project is mostly defunct today, I'll always appreciate the
opportunity it gave me to learn about developing web apps for the first time.
I'm hoping to bring it up to speed with my current skillset at some point -
probably giving it a top-to-bottom rewrite, with better-structured code and a
new look.
