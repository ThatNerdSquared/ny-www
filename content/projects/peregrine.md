What makes for a good note-taking environment? How can we use time to organize
notes? How do we express good note-taking practices such as atomicity and
reusability in software?  These are just some of the questions I'm exploring
through Peregrine, a note-taking tool I've been working on for a few years now.

After experimenting with various note-taking methods, including Zettelkasten,
I've formed some distinct opinions on what a good note-taking system needs to
fulfill in order to allow productive development of thoughts. I've also tried
several note-taking apps, primarily using Obsidian for a couple years before
deciding to build out Peregrine. My hope is to explore some different design
ideas and interfaces I think might fit the needs of note-takers better.

I'll have more to say about Peregrine soon — keep an eye out for project updates
and an initial release soon. In the meantime, if you're curious about the
philosophy behind the project, I'd recommend reading [Incremental
note-taking](https://thesephist.com/posts/inc/) by [Linus Lee
(@thesephist)](https://thesephist.com). This article along with Linus' work more
generally formed part of my initial inspiration for Peregrine, and continue to
be useful theoretical building blocks for this project today.
