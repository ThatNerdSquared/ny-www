Raycast is a command launcher for macOS, with extensions that let you do things
like check GitHub issues and run scripts entirely from your keyboard. In 2022, I
realized there wasn’t a good way to run timers and stopwatches within Raycast
without the need for third-party software. Following this, I wrote an extension
designed to handle timers directly within the Raycast UI. This became Timers for
Raycast, which I’ve maintained for well over two years now.

Since then, the project has grown significantly, amassing an install base of
over 35,000 users (and counting!). I’ve had the opportunity to hone my
Typescript skills, work with Raycast staff and code reviewers, and talk to users
to fix bugs and create new features. I’ve also watched the Raycast Extension API
itself grow in response to the huge increase in usage, and helped to push the
boundaries of what’s possible for a Raycast extension.
